# 副技能抽选设定

共享设定在 `subskill-draw.json`，由 `calc/data.ts` 的 `SUBSKILL_DRAW` 导出。概率使用 0～1 的比例，不是百分数。此次补充资料设定，不新增随机生成或厳选概率计算入口，不改变现有个体收益计算。

## 概率与抽选过程

- 先抽颜色：金色 14%、蓝色 33%、白色 53%。
- 再从该颜色尚未选中的副技能中等概率抽取；同一个体不能出现重复技能。
- 当前完整候选池为 7 金、6 蓝、4 白，所以尚未排除技能且没有锁金时，每种技能的基础概率分别为 2%、5.5%、13.25%。这些不是五个槽位各自恒定的概率，也不是整只宝可梦拥有该技能的概率。
- 后续抽选仍采用颜色概率，在该颜色剩余技能中均分；不能把每种技能基础概率作为权重，在全部剩余技能之间统一归一化。
- 四种白色已全部抽出后，第五槽若再次抽到白色，则改抽金色，此时金色概率为 67%、蓝色为 33%。五槽范围内金色和蓝色池不会耗尽，因此不设未经核实的其他颜色兜底。

## 友情徽章

`goldSlotsByTier` 使用从 0 开始的槽位索引，依次对应无、铜、银、金徽章。启用徽章效果时，第一、前二、前三槽分别锁金；锁金槽位仍须排除已经选中的技能。银徽章起允许分别开关各锁金槽位，不能一律根据友情等级强制锁金。物种所需友情等级继续使用 `ingredients.ts` 的既有 `MEDAL_LEVELS` 与图鉴 `medalGroup`，此次不修改门槛或现有展示。

## 来源与冲突

核对日期：2026-10-12。优先级：官方公告 > RAE > Wiki。

- [官方 Ver.2.7.0 公告](https://www.pokemonsleep.net/zh/news/323537323733323635393039363631363937/)（2025-04-17）：确认三个金色槽位及银徽章起可分别开关的规则，未公开抽选概率。
- [RAE 游戏机制：副技能概率](https://pks.raenonx.cc/zh/docs/view/mechanics/subskill-probability)（页面更新 2025-12-09）：2024-08-24 分析的 44,765 个初始皮卡丘样本，给出每种金/蓝/白 2%/5.5%/13.25%，以及先颜色后技能、白色耗尽转金的规则。本项目采用该研究模型，不称为官方确认；样本来自初始皮卡丘，对普通捕捉个体的应用属于模型假设。
- [Wiki 副技能](https://wikiwiki.jp/poke_sleep/サブスキル)与[抽选验证](https://wikiwiki.jp/poke_sleep/検証/サブスキル抽選確率)：旧推定采用每种 2%/6%/12.5%，与 RAE 蓝/白概率不同，按优先级采用 RAE。Wiki 小样本的最终出现占比不能直接替代逐槽抽选概率。

锁金规则为官方机制；普通概率与抽选细节为研究模型。未加入研究等级、睡姿星级、闪光或宝可梦专长对概率的额外修正，也不覆盖活动固定个体。资料引用在产品中只放在鸣谢。
