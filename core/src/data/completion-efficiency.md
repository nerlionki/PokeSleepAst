# 补齐效率计算口径

- 仅选择睡姿图鉴中未收集、可参与普通睡眠研究的睡姿。复用 `resolvedSleepdex` 与 `styleKey`；跨岛同一睡姿共用状态，同星不同睡姿不合并。活动限定睡姿不进入普通研究搜索。
- 目标是每天至少出现一次指定睡姿的概率。同觉重复出现不重复计成功。两觉按相同卡比兽能量、分数合计 100 计算；每日成功概率为 `1 - (1 - p1) * (1 - p2)`，同时比较整觉 100 分。
- 不增加未发现睡姿权重，不因图鉴状态改变抽选池。只统计普通研究，沿用宝宝效率的抽选规则、岛屿保底、特殊宝可梦与大肚睡限制，以及活动倍率与跨睡眠类型设置。
- 默认沿用宝宝效率：4000 次模拟、中精度、活动倍率 1、跨类型关闭、全部岛屿与睡眠类型自动择优、允许比较拆觉；每觉睡意之力上限 50 亿。
- 能量候选点、精度细化与蒙特卡洛抽样均沿用共享搜索。展示的是本次候选搜索的模拟最优值，不保证连续能量全域的真实最大值；概率也不是官方公布的出现率。
- 抽选资料沿用项目已记录的研究模型：[RAE 睡意之力及睡姿抽选说明](https://pks.raenonx.cc/zh/docs/view/help/sleep-styles)、[Wiki 睡姿出现法则](https://wikiwiki.jp/poke_sleep/睡眠リサーチ/ねむけパワー/寝顔出現の法則)。2026-10-19 复用现有项目模型，本次不修改游戏资料或抽选规则。上述概率定义、不增加未发现权重及仅未收集目标均经用户确认。
