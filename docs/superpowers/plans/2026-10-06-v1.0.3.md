# 1.0.3 Implementation Plan

**Goal:** Deliver Android 1.0.3 and a complete Taro WeChat client with shared core and experimental OCR.

**Architecture:** Move shared domain modules, data, assets and reusable Vue UI into core. Keep platform entry points and adapters in app and wxapp. Generate WeChat-compatible view sources from shared UI at build time, adapting native form controls and platform APIs without maintaining duplicate UI sources.

**Tech Stack:** TypeScript, Vue Composition API, Pinia, Vite, Capacitor, Taro Vue3, WeChat local inference.

**Spec:** ../specs/2026-10-06-v1.0.3-design.md

## Global Constraints

- Branch `1.0.3`; version `1.0.3`; AppID `wxa305c12ee6676e08`.
- Sibling directories `app`, `wxapp`, `core`.
- Complete feature migration; experimental WeChat OCR is user-verified on device.
- Manual update check on Android only.
- Preserve pre-existing staged and unstaged user changes.
- No new accounts, backend or automatic synchronization.

## Review Focus

- Faded ingredient icons and misleading quantities must not turn ABB into ABC.
- WeChat selectors, booleans and numeric input must preserve value types and selection behavior.
- Storage failures and backup round trips must not silently overwrite box contents.
- Unavailable OCR models or inference must explain failure and preserve manual entry.
- Expensive baby calculations must retain cancellation and progress on WeChat.
