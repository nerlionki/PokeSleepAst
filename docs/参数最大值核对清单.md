# 项目参数最大值核对清单

核对日期：2026-10-06。范围：项目当前共享源码 `core/src` 及本地 JSON 资料。Android/Web 的 `app/src` 对相关模块转导出或包装；微信由 `wxapp/scripts/prepare.mjs` 从共享源码生成。

本次已按核对结果调整：食谱最高 70 级；个体产量、队伍时序及成员卡片的主技能有效等级都按对应技能表封顶；技能型／全能型储存最多 2 次，其他最多 1 次。两端共享这些规则。

本文记录**当前实现**，未与游戏官方最新规则作外部核验。界面最大值、计算封顶、资料中的最大记录是三个不同口径；资料极值不等于游戏规则上限。HTML 数字输入的 `max` 仅是表单约束，不能据此认定数据会被自动截断。

## 6. 优先核对的口径差异

- [ ] **等级 100 与经验表 70**：产量可算到 100，但养成表超过 70 缺失；养成页又不限制输入，查不到累计经验时返回 0。
- [x] **技能 8 与计算 6**：已移除固定六级效果数组，改按主技能表的等级和值读取；副技能加级同步封顶。复合技能机制仍按已有模拟范围实现，蓄力使用 0 层值，区间能量使用均值。
- [x] **通用技能输入仍为 6**：`core/src/components/shared/PanelFields.vue` 已按当前宝可梦主技能动态设置上限。
- [x] **食谱等级 70**：设置、料理计算、食谱和锅资料页已同步至 70。
- [x] **技能储存次数**：已统一专长规则，并测试睡眠期间反复发动后的存储和起床释放，技能型／全能型 2 次，其余 1 次。
- [ ] **基础锅 15 与界面最小 21**：默认 15、天青沙滩自动值 18，都低于设置框声明的最小值。
- [ ] **“持有无上限”实为 9999**：需要确认是否符合模拟意图。
- [ ] **进化次数、银种子记录与效果**：编辑器可记录，但当前持有公式未计入进化次数；应核对这些记录是否只用于展示。
- [ ] **增强配额为提示**：350／3500 不会阻止计算；100000 是单行手动糖果输入限制。
- [ ] **糖果基础经验口径**：糖果规划低等级 40／35 EXP，通用养成固定 25 EXP。
- [ ] **表单约束与真正封顶**：睡眠分数、锅容量、哨子等 `max` 未统一在设置加载和计算入口执行校验。
- [ ] **概率封顶口径**：个体对比显式封顶 100%，队伍时序直接使用修正概率；现有资料尚不触及这一差异。
- [ ] **资料数量元信息**：`meta.json` 写图鉴 247，实际 `pokedex.json` 有 249 条记录；记录数包含形态，不能直接等同于物种数。
